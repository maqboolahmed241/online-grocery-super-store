# Online Grocery Super Store

First mobile-friendly Urdu / English / Sindhi storefront prototype.

Includes product browsing, search, categories, cart, checkout form, local-device order history, demo admin controls, PKR 15,000 free-delivery threshold, PWA manifest and basic offline shell.

**Prototype limitation:** data is stored only in each browser's localStorage. Orders do not reach the shop owner and admin changes are not shared across devices. Firebase Firestore + secure Authentication, the real delivery area and store WhatsApp number must be configured before live use. Do not use this demo as a live ordering system yet.
